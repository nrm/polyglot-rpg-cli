# Polyglot-RPG Utilities

Post-processing tools for [marker](https://github.com/datalab-to/marker) output to prepare content for Polyglot-RPG translation pipeline.

These utilities help convert PDF documents (converted to Markdown by marker) into structured, split chapters ready for TTRPG translation workflows.

---

## 📚 Tools Overview

### 1. split_markdown.py
**Splits markdown files into logical chapters based on document structure.**

Designed for documents with major # (heading level 1) sections that correspond to chapters or sections.

#### Usage
```bash
python3 split_markdown.py <markdown_file> <metadata_json>
```

#### Arguments
- `markdown_file` - Path to markdown file (output from marker)
- `metadata_json` - Path to metadata.json (generated by marker alongside the markdown)

#### Examples
```bash
# From utils directory, processing a file in parent
python3 split_markdown.py ../example_project/my_document/document.md \
                          ../example_project/my_document/document_meta.json

# From the document directory
cd ../example_project/my_document
python3 ../../utils/split_markdown.py document.md document_meta.json
```

#### Output
Creates a `02_input_chapters/` directory (in the same location as the markdown file) containing:
- `0_Introduction.md` - Introductory material
- `1_FirstChapter.md` - First main chapter
- `2_SecondChapter.md` - Second main chapter
- etc.

#### How It Works
1. Parses the markdown file to find all # (level 1) headings
2. Uses metadata.json to understand document structure
3. Identifies major section boundaries
4. Splits the document at these boundaries
5. Validates that no content is lost during splitting
6. Writes individual chapter files

#### Example Output
For a typical TTRPG sourcebook:
```
Original: sourcebook.md (1,525 lines, 147 KB)
          ↓ split_markdown.py
Output:
  0_Introduction.md (62 lines)
  1_Chapter_One.md (302 lines)
  2_Chapter_Two.md (424 lines)
  3_Chapter_Three.md (320 lines)
  4_Chapter_Four.md (417 lines)
```

### 2. validate_split.py
**Validates that markdown splitting preserved all content.**

Performs comprehensive integrity checks to ensure:
- No text was lost
- All images/figures are referenced
- All markdown formatting is intact
- Word/character counts match
- All headings are preserved

#### Usage
```bash
python3 validate_split.py <original_markdown> <chapters_directory>
```

#### Arguments
- `original_markdown` - Path to the original markdown file (from marker)
- `chapters_directory` - Path to the directory with split chapters (e.g., 02_input_chapters)

#### Examples
```bash
# Validate splitting was successful
python3 validate_split.py ../example_project/my_document/document.md \
                          ../example_project/my_document/02_input_chapters

# From document directory
cd ../example_project/my_document
python3 ../../utils/validate_split.py document.md 02_input_chapters
```

#### Validation Checks (9 total)
1. **Character Count** - Original and combined chapters match
2. **Line Count** - All lines preserved
3. **Headings** - All markdown headings present
4. **Images** - All image references intact
5. **Code Blocks** - All code blocks preserved
6. **Links** - All hyperlinks preserved
7. **List Items** - All list markers preserved
8. **Word Count** - Exact word count match
9. **Chapter Structure** - All chapter files present

#### Output
Returns detailed report showing:
- ✅ PASS / ❌ FAIL for each check
- Character and word count statistics
- File-by-file breakdown
- Overall validation result

#### Example Output

## 🔄 Typical Workflow

### Step 1: Convert PDF to Markdown using marker
```bash
marker_pdf <your_document.pdf> -o ./output_dir
# This produces:
#   - output.md (markdown content)
#   - output_meta.json (metadata from PDF)
#   - image files (_page_*.jpeg, etc)
```

### Step 2: Split markdown into chapters
```bash
cd /path/to/polyglot-rpg-cli/utils

python3 split_markdown.py /path/to/output.md /path/to/output_meta.json
# Creates: 02_input_chapters/ directory with split chapters
```

### Step 3: Validate splitting
```bash
python3 validate_split.py /path/to/output.md /path/to/02_input_chapters
# Should show: ✅ ALL VALIDATION CHECKS PASSED!
```

### Step 4: Use with Polyglot-RPG
```bash
cd /path/to/document
polyglot-rpg init .
polyglot-rpg create-glossary . --use-llm --pre-translate
# ... review and approve glossary ...
polyglot-rpg translate .
```

## 🎯 Use Cases

### Perfect for:
- ✅ Large TTRPG sourcebooks (D&D, Pathfinder, etc)
- ✅ Technical documentation with clear chapter structure
- ✅ Academic papers with distinct sections
- ✅ Any multi-chapter PDF with major heading divisions

### How to structure your document:
The splitting is based on # (heading level 1) sections. Organize your PDF with:
```
# Chapter 1
...content...

# Chapter 2
...content...

# Chapter 3
...content...
```

Each # heading becomes the start of a new chapter.

## 🔧 Customization

### For different document types:
If your document has a different structure, you can:

1. Modify `split_chapters()` method in `split_markdown.py` to look for different heading patterns
2. Update the chapter naming scheme
3. Adjust the validation rules in `validate_split.py`

### Example: Adjust heading level
```python
# To split on ## (heading level 2) instead:
if re.match(r'^## ', line):  # Changed from r'^# '
    # ...
```

## 🐛 Troubleshooting

### "File not found" errors
- Use absolute paths or run from the correct directory
- Check that file extensions are correct (.md, .json)

### Validation fails
- Run split again - validation results should show what's wrong
- Check that metadata.json is from marker (has 'table_of_contents' key)

### Chapter count is wrong
- Document structure may not have enough # headings
- Check for ## or ### instead - may need to adjust heading level

### Images are missing
- Images are NOT copied by these tools (only markdown text)
- Copy image files (\_page_\*.jpeg, etc) from marker output manually
- These tools only process text content

## 📝 Marker Output Structure

When marker processes a PDF, it creates:

```
output_directory/
├── output.md                   ← Markdown file (processed by split_markdown.py)
├── output_meta.json            ← Metadata (processed by split_markdown.py)
├── _page_0_Picture_0.jpeg      ← Images (referenced in markdown)
├── _page_1_Figure_0.jpeg
├── _page_2_Figure_1.jpeg
└── ... more images ...
```

These tools process the `.md` and `.json` files only. Images are already in the right location - just need to copy them along with the split chapters.

4. **Run translation** on the split chapters

The split chapters work seamlessly with Polyglot-RPG's translation pipeline.
