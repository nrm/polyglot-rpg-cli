# TODO: Улучшение кеширования переводов с учетом глоссария

## Проблема

**Текущая реализация** (`main.py:192-226`):
```python
def translate_chunk(self, chunk: str) -> str:
    cached = self.cache.get(chunk)                      # ❌ проверяем кеш по оригиналу
    if cached:
        return cached

    text_to_translate = self.glossary.apply_to_text(chunk)  # применяем глоссарий
    # ... отправляем text_to_translate в LLM ...

    self.cache.set(chunk, translation)                  # ❌ кешируем по оригиналу
```

**Суть проблемы:**
- Кеш проверяется и сохраняется по ключу `hash(оригинальный_текст)`
- Глоссарий применяется ПОСЛЕ проверки кеша
- При изменении глоссария старый кеш остается валидным, хотя перевод должен измениться

**Пример:**
1. Глоссарий v1: `{wizard: "маг"}`
   - Текст: `"The wizard attacks"` → `hash("The wizard attacks")` → кеш: `"Маг атакует"`
2. Пользователь меняет глоссарий v2: `{wizard: "волшебник"}`
3. При повторном переводе:
   - Проверяется `hash("The wizard attacks")` — найден в кеше!
   - Возвращается старый перевод: `"Маг атакует"` ❌
   - Новый термин "волшебник" не применяется ❌

**Единственное решение сейчас:** Удалить весь кеш вручную:
```bash
rm .cache/translations_cache.json
```

## Предложенное решение

**Применять глоссарий ДО проверки кеша** и **кешировать по обработанному тексту:**

```python
def translate_chunk(self, chunk: str) -> str:
    # ✅ Применяем глоссарий СРАЗУ
    text_to_translate = self.glossary.apply_to_text(chunk)

    # ✅ Проверяем кеш по ОБРАБОТАННОМУ тексту
    cached = self.cache.get(text_to_translate)
    if cached:
        return cached

    # Оборачиваем текст в теги <data>
    user_message_content = f"<data>\n{text_to_translate}\n</data>"

    # ... отправляем в LLM ...

    # ✅ Кешируем по ОБРАБОТАННОМУ тексту
    self.cache.set(text_to_translate, translation)
    return translation
```

**Результат:**
- Глоссарий v1 `{wizard: "маг"}` → кеш по ключу: `hash("The маг attacks")`
- Глоссарий v2 `{wizard: "волшебник"}` → кеш по ключу: `hash("The волшебник attacks")` (другой хеш!)
- Автоматически пересчитаются **только те chunks, где изменились термины**
- Chunks без затронутых терминов останутся в кеше и не потребуют повторного перевода
